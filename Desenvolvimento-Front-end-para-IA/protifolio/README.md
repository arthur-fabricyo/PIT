# Portfólio — Arthur Fabrícyo

Portfólio pessoal desenvolvido com HTML, CSS e JavaScript puro.

## Como executar

Abra `index.html` diretamente no navegador ou rode um servidor local:

## Estrutura

- `index.html`: estrutura da página
- `style.css`: estilos e responsividade
- `script.js`: lista de projetos e renderização dos cards

## Personalização

Os projetos ficam no array `projetos` dentro de `script.js`.
Basta editar título, tecnologias, descrição, badges e links.
